# 贵阳住宿专题

参考源：D:/code/wenlv-screen/src/main/resources/static/accommodation-integrated-screen/。

保留参考页面的三列布局、GT Design 装饰素材、分类供给、日月年趋势、价格与住宿时段、客源结构、机会分析和双向住宿路径弹窗。画布按 1920×1080 等比适配。

从原版综合大屏的六业专题抽屉点击“住”进入独立住宿专题，左上角返回综合大屏。文化、旅游入口也在该抽屉内。V2 页面未修改。

默认范围为贵阳市，地图与区域选择器支持十个区县联动，区县筛选更新供给、接待及消费模拟数值。地图返回止于贵阳。跨市住宿路径和机会分析明确采用贵阳全市口径，不随区县变化。省内外客源保持来源地含义，不跳转为其他城市的监测大屏。

经营指标为原型模拟数据，不是同程、银联或官方发布数据。地图使用项目已有的真实贵阳行政区界，本专题未将功能区拼接为独立行政区。

验证：JavaScript 语法、全部页面依赖 HTTP 200，以及 work/check-accommodation.cjs 的模拟 DOM 交互检查。当前浏览器插件缺少 scripts/browser-client.mjs，未完成实际浏览器截图与视觉检查。
